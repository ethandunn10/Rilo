Why does your app need Family Controls (Screen Time) access?

Rilo is a screen time app that helps people cut back on the apps they lose time to, like TikTok or Instagram. It is for the person using the iPhone to manage their own screen time, so it asks for individual authorization (.individual). It is not a parental control app and does not monitor anyone else.

Bundle IDs that need the entitlement:
- com.ethandunn.Rilo (the app)
- com.ethandunn.Rilo.RiloShieldConfiguration (shield configuration extension)
- com.ethandunn.Rilo.RiloShieldAction (shield action extension)
- com.ethandunn.Rilo.RiloActivityMonitor (device activity monitor extension)

Rilo uses the Screen Time APIs for these things:

1. FamilyControls: the person picks the apps they want help with in Apple's own app picker (FamilyActivityPicker). Rilo only gets Apple's tokens for those apps, never their names or bundle IDs. Inside Rilo, app names and icons are drawn by iOS from the tokens (Label). Optionally, in settings, the person can type a name for a picked app; those names come only from what the person tells Rilo and stay on the iPhone.

2. ManagedSettings: Rilo puts a shield on the picked apps. Each app gets a few "opens" a day, and each open lasts a set number of minutes. On the shield, the person taps "open" and waits a few seconds (longer with each open that day); then Rilo lifts the shield on that one app for one open. When the opens run out, the app stays shielded until midnight. People can also block an app fully, or block apps during bedtime, school hours or a focus block they set. An optional strict mode turns on "deny app removal", so the person can't just delete an app to get around their own limits.

3. DeviceActivity: Rilo schedules a daily reset at midnight (fresh opens), and it watches each open's minutes so the shield goes back on when they are used up, even if Rilo is closed.

4. Shield configuration and shield action extensions: these show Rilo's own message on the shield (the app's name, which Apple provides to this extension, how many opens are left today, and the wait), an "open" button that runs the short wait and then lifts the shield for one open, a "talk to rilo" button that opens Rilo's check-in when the app is locked, and a "never mind" button. While an open is running, a Live Activity shows the time left; tapping it opens Rilo so the person can end the open early.

Rilo also offers an optional App Intent, "Rilo check-in" (off by default, in settings), that the person can add to their own Shortcuts automation ("when Instagram is opened, run Rilo check-in"). It opens Rilo's check-in for that app. While that automation handles an app, Rilo keeps that app's shield down except when it is out of opens, blocked, in a schedule, or its session time has just run out, so the shield and the check-in never show at the same time.

Rilo also has a home screen widget. It shows Rilo's mood and how many opens are left today. It does not use the Screen Time APIs; it reads that summary from the app's App Group on the phone.

Everything stays on the iPhone. Rilo has no accounts, no server and no analytics. No Screen Time data, app list, app names or usage is sent anywhere, shared or used for ads. The only thing that can leave the phone is a weekly share image (minutes saved, streak and level), and only when the person taps share and picks where to send it.
